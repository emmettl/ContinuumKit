# Public stabilized affine consumer

Run `bash Scripts/check-affine-fit-consumer.sh [EXACT_VERSION] [OUTPUT]` from a
clean committed checkout. The consumer fetches that committed Git source/version,
imports only public `Numerics`, compiles optimized and retains all native inputs,
results/diagnostics/queries, failure categories, source/hardware/toolchain/flags,
resolved pins and linkage. No model, application, UI, Metal or Accelerate is linked.

The 300-case tree retains all 188 protected original audit inputs, wider scaling/
reversal/extreme cases and explicit invalid requests. Independent rational references
validate the new fits; inaccurate/nonfinite originals remain original findings.
Thirteen deliberate coherent-bit and scope/query corruptions challenge the verifier.
See [the contract](../../docs/extraction/AFFINE_LEAST_SQUARES.md). Release and full
RoomCAD parameter/noise/calibration adoption remain separate gates.
