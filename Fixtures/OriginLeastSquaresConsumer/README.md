# Origin least squares consumer and production-source witnesses

Run `bash Scripts/check-origin-least-squares-consumer.sh [VERSION] [OUTPUT]` from
a clean committed candidate. It builds an optimized separate Git consumer,
requires no Metal/UI/Accelerate linkage, and compares every public output with a
passive source-bound probe. Original source bytes are recoverable from the recorded
bindings. All 450 cases, native array bytes, exact integer arithmetic stages,
coefficient/query outcomes, independent rational findings and nine rejecting
controls are retained. Limit vectors are fully expanded in the native binary
witnesses; their pattern descriptions do not replace actual input bytes.

See [the candidate contract](../../docs/extraction/ORIGIN_LEAST_SQUARES.md).
