# Bounded isotropic tetrahedral element extraction

`SolidMechanics.IsotropicTetrahedron` transfers the current Edgerton element and
its private objective work-correction helper. Arithmetic is unchanged. The declared
transformations rename the element/error/helper and expose its existing inline
four-corner response, gradients and read-only rest gradients. Both array and inline
paths travel; no hot-path replacement is imposed on future application adoption.
Edgerton source, dependencies, defaults, recordings and evidence remain unchanged.
Adoption is deliberately deferred to a separate bounded application task.

## Chosen laws and units

Rest/current coordinates are m; shear G and bulk K are Pa; energy is J; nodal forces
N; Cauchy stress Pa, tension positive; J is the dimensionless determinant of F.
The three retained response options are:

- Isochoric neo-Hookean/log-bulk: W = G/2*(J^(-2/3)*tr(FᵀF)-3)+K/2*log(J)^2.
- Saint-Venant–Kirchhoff: W = G/4*norm(FᵀF-I)^2+(K-2G/3)/8*tr(FᵀF-I)^2.
- Saint-Venant–Kirchhoff/log-barrier: the previous trace coefficient subtracts A,
  and W adds A*(J-1-log(J)), where A=barrierFraction*K.

W is per rest volume. The default is the neo-Hookean/log-bulk law. The constructor
retains positive finite G/K, four finite rest corners, abs(rest determinant)>1e-18
and 0<barrierFraction<1 (default .05) checks. Rest volume uses absolute determinant.
Callers must keep coordinate/matrix arithmetic representable; no arbitrary
extreme-input robustness is introduced by this source-preserving extraction.
All laws require positive current J; the plain StVK option does not add an
inversion-energy barrier. Parameters are chosen model inputs, not material calibration.

`evaluate` returns energy, J and conservative nodal forces. `cauchyStress` retains
source stress reconstruction. `forceDifferential` retains the analytic directional
derivative; `stressDifferentialNormBound` is a constitutive Frobenius operator-norm
bound, not a contact/dynamics timestep certificate. The objective discrete gradient
uses positive-J endpoints and midpoint plus the unchanged finite-work correction
threshold. It does not own a time integrator, damping, contact, fracture or history.
`ElementError.invalidDefinition` replaces the application geometry error identity.

## Verification and evidence

Immutable guards freeze original kernel and helper block hashes; public source is
reconstructed with only declared names/visibility changes. The original kernel is
a verification-only fetched-consumer target, with a small inline probe compiled in
that target. No application source or oracle is regenerated through Core.

New independent 45-digit Decimal references cover twelve diagonal states across
all three laws, directly checking energy density, J and Cauchy stress. Their small
CSV and generator are committed and byte-regenerated by the source guard. Further
checks cover energy/force derivatives, analytic directional tangent, rigid-frame
objectivity, material isotropy, net force/torque, finite-step work/midpoint torque,
array/inline agreement, translation nullspace and definition/inversion rejection.
These are element checks; assembled cavity/Apple/refinement evidence stays in Edgerton.

The optimized clean consumer compares eighteen three-law states against the frozen
original: exact energy/J/forces, Cauchy stress, directional tangent and norm bound,
array work gradient, inline response and inline work gradient. CPU-only linkage is
required. Full package and exact-tag checks precede any Core publication; application
adoption later verifies both public paths and affected coupled mechanics/rollback.
No whole-target convergence, empirical material accuracy or impact claim is made.
Generated logs/builds remain outside GitHub and compute yields to feature work.
